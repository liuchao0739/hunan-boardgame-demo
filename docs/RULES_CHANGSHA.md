# 长沙麻将规则（本项目实现）

## 牌库

万、条、筒各 1–9 ×4 = **108** 张（无字牌）。编码：`0–8` 万，`9–17` 条，`18–26` 筒。

## 基础

- 4 人；庄家 14 张，闲家 13 张
- 可吃（仅上家）、碰、明杠、暗杠、补杠、炮胡、自摸
- 默认抓鸟 2 张；中鸟加分
- 一炮多响：`rules.multiHu = "all"` 时多家同时胡；`"first"`（默认）时先胡者独赢

## 番型与将将胡

| 番型 | 番 | 说明 |
|------|-----|------|
| 平胡 | 1 | 标准 3N+2 |
| 自摸 | +1 | 与平胡叠加 |
| 将将胡 | +2 | 手牌全为 2/5/8 且能胡；**与平胡叠加，非互斥** |
| 抢杠胡 | +1 | 补杠时被胡 |
| 杠上花 | +1 | 杠后自摸（预留） |

起手胡、中途胡各 **2 番**，计入 `settle.detailItems` 流水。

## 杠分（即时结算，相对 baseScore）

| 类型 | 计分 |
|------|------|
| 明杠 | 点杠者出 2，其余各出 1 |
| 暗杠 | 其余三家各出 2 |
| 补杠 | 其余三家各出 1 |

杠分写入 `snapshot.scoreLedger.gang`。

## 抓鸟

胡牌后从牌墙顺摸 `birdCount` 张（默认 2）。鸟牌 **点数**（1–9，与花色无关）映射 **相对胡家** 的座位偏移：

| 鸟牌点数 | 中鸟座位（相对赢家偏移） |
|----------|--------------------------|
| 1、5、9 | 赢家本人（偏移 0） |
| 2、6 | 下家（偏移 +1） |
| 3、7 | 对家（偏移 +2） |
| 4、8 | 上家（偏移 +3） |

例：赢家座位 0，鸟牌 2万 → 中座位 1。实现见 `niao.lua` 的 `bird_hit_offset` / `count_hits`。

## 起手胡（发完牌检测）

板板胡、缺一色、六六顺、步步高、金童玉女、三同、一枝花、将将胡、大四喜。  
可多家同时成立；演示局会先结算起手分，再点「继续打牌」。

## 中途

中途四喜、中途六六顺（摸牌后检测并加分，写入 `scoreLedger.zhongtu`）。

## 荒庄

牌墙余牌为 0 时下一巡摸牌触发荒庄，正常写入 `settle` 无异常。
