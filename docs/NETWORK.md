# 湘桌联网说明

本项目 **不是单机**：客户端通过 WebSocket 连 **Skynet** 权威服，房间状态在服务端。

默认看起来像单机，是因为点「创建房间」会 **自动补机器人**（人机练习）。要真联机用 **好友房**。

---

## 架构

```
浏览器 A ──┐
           ├── ws://主机IP:9948 ── Skynet ws_gate ── room_mgr ── 房间逻辑
浏览器 B ──┘
```

- 服务端：`server/` · `./run.sh` · 监听 `0.0.0.0:9948`
- 客户端：`GameApp.wsUrl` 默认 `ws://127.0.0.1:9948`

---

## 本机双开联机（最快）

1. 启动服务端：

```bash
cd server && ./run.sh
```

2. Cocos 预览开 **两个浏览器窗口**（或一个预览 + 一个手机浏览器，见下）。

3. **窗口 A（房主）**
   - 选玩法
   - 点大橙键 **好友房**（不是绿色「创建房间」）
   - 弹出房号，例如 `A3K9P2`
   - 可先点「关闭」等好友；人不够可点「补机器人开打」

4. **窗口 B（好友）**
   - 控制台先改昵称（可选）：`window.__nick="好友"`
   - 点 **加入房间** → 数字键盘输入房号 → 加入

5. 人齐后房主点牌桌 **再来一局/准备**（或补机器人）即可开打。

绿色 **创建房间** = 人机快开（自动 `fill_bots`），适合单人演示。

## 局域网 / 真机

1. 查电脑局域网 IP（如 `192.168.1.8`）。
2. 服务端已监听 `0.0.0.0:9948`，确保防火墙放行。
3. 手机/另一台电脑浏览器打开同一预览地址，或打包后在客户端设置：

```js
window.__ws = "ws://192.168.1.8:9948"
window.__nick = "手机玩家"
// 然后刷新页面
```

`GameApp` 会在 `onLoad` 读取 `__ws` / `__nick`。

公网部署需：云主机跑 Skynet + 反代 WSS + 客户端改 `wss://你的域名`。

## 控制台备忘

| 变量 | 作用 |
|------|------|
| `window.__join="房号"` | 旧方式：设好后点加入 |
| `window.__room` | 最近创建的房号（自动写入） |
| `window.__nick` | 昵称 |
| `window.__ws` | WebSocket 地址 |
