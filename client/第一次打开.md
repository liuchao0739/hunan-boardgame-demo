# 装好 Creator 后：第一次打开工程（照着点）

Creator：`/Applications/Cocos/Creator/3.8.8/CocosCreator.app`  
工程：`/Users/liuchao/hunan-boardgame-demo/client`  
Skynet：`ws://127.0.0.1:9948`

## 重要：别在「资源管理器」里找 2D

| 面板 | 位置 | 用来干什么 |
|------|------|------------|
| **层级管理器** | 左上 | 往场景里加节点（Canvas）← 在这里建 |
| 资源管理器 | 左下 | 建脚本、场景文件、材质 |

「2D / UI」只出现在 **层级管理器** 的右键菜单，不在资源管理器。

---

## 正确步骤

1. 已有 `assets/scenes/Main` 并双击打开（你已完成）
2. 场景视图左上角把 **3D** 切成 **2D**（可选）
3. 在 **层级管理器**（左上，有 Main / Main Light / Main Camera）空白处 **右键**：
   - **创建 → UI 组件 → Canvas**
   - 或：**创建 → UI → Canvas**
4. 选中 **Canvas**
5. 右侧检查器 → **添加组件** → 搜 **`GameApp`** → 添加
6. `wsUrl`：`ws://127.0.0.1:9948`
7. 保存场景 → 顶部 **预览 ▶**

可选：删掉 `Main Light`（纯 UI 不需要）。
