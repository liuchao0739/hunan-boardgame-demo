# 欢乐麻将能力对照（湘桌对标基线）

「完全对标」= 下列能力达到**可上线的商业地方麻将平台**水准，非腾讯素材/品牌复刻。

| 能力域 | 欢乐麻将典型能力 | 湘桌现状 | 目标 phase |
|--------|------------------|----------|------------|
| 规则 | 完整番型、杠分、抢杠、多响策略 | 简化 3N+2 + 起手/鸟 | phase1 |
| 对局会话 | 断线重连、托管、倒计时、续桌 | 断线即离房 | phase2 |
| 账号 | 登录、资料、战绩 | 内存起名 | phase3 |
| 牌桌表现 | 发牌/出牌/胡动效+语音 | 状态刷新为主 | phase4 |
| 匹配社交 | 快速开始、好友房、表情 | 房号+机器人 | phase5 |
| 经济 | 房卡/钻石、流水 | 假房卡字段 | phase6 |
| 多玩法 | 多麻将/扑克入口 | 长沙可玩、跑胡子占位 | phase7 |
| 运维 | 监控、备份、灰度 | 手动部署 | phase8 |
